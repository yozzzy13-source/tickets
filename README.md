# Shanghai Masters 2026 — монитор билетов

Следит за официальным англоязычным магазином (ztmen.jussyun.com) и пишет в
Telegram, когда на **полуфинал (17.10)** или **финал (18.10)** появляются
места. Логин не нужен, покупка — руками.

## Что делает

- открывает магазин headless-браузером раз в 90 секунд (ночью по Шанхаю реже),
- перехватывает внутренние запросы сайта и вытаскивает из них секторы, цены и остатки,
- переводит юани в доллары и делит на «в бюджете» / «дороже потолка»,
- пишет только когда состояние поменялось, а не каждую минуту,
- раз в сутки присылает тихое «жив».

## Деплой на Railway

1. Залить эту папку в приватный репозиторий на GitHub.
2. Railway → New Project → Deploy from GitHub repo. Dockerfile подхватится сам.
3. Variables — прописать:

```
TELEGRAM_BOT_TOKEN=токен от @BotFather
TELEGRAM_CHAT_ID=твой chat id
MAX_PRICE_USD=300
GOOD_PRICE_USD=200
TARGET_QTY=2
CHECK_INTERVAL_SECONDS=90
CNY_PER_USD=7.1
TICKET_URL=https://ztmen.jussyun.com/
STATE_FILE=/data/state.json
```

4. Settings → Volumes → добавить том, mount path `/data`. Без него бот после
   перезапуска забудет, что уже присылал, и продублирует уведомление.
5. Deploy. В чат придёт «Монитор запущен».

Chat id: написать боту любое сообщение и открыть
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` — там будет `"chat":{"id":...}`.

## Команды бота

| Команда | Что делает |
|---|---|
| `/help` | список команд |
| `/status` | жив ли, сколько проверок, текущие настройки |
| `/check` | проверить прямо сейчас |
| `/last` | что было видно на последней проверке |
| `/price 300` | поменять потолок в долларах |
| `/qty 2` | сколько билетов нужно |
| `/snapshot` | прислать дамп страницы и найденных запросов |
| `/pause` / `/resume` | пауза и возобновление |

Список для меню бота (@BotFather → /setcommands):

```
help - список команд
status - статус монитора
check - проверить сейчас
last - последняя проверка
price - потолок цены в долларах
qty - сколько билетов нужно
snapshot - дамп для отладки
pause - пауза
resume - продолжить
```

## Первый запуск: обязательно сделать `/snapshot`

Магазин — одностраничное приложение, структуру его внутренних запросов снаружи
не видно. `/snapshot` пришлёт JSON: какие адреса дёргает сайт и что из них
удалось распознать. По этому файлу за пять минут донастраиваются:

- `TARGETS` в `monitor.py` — шаблоны дат сессий,
- `PRICE_KEY_HINTS` / `STOCK_KEY_HINTS` / `STATUS_KEY_HINTS` — названия полей,
- `normalise_price_cny` — если цены приходят в фэнях, а не в юанях.

Пока не сверились со снапшотом, считай что бот работает в режиме
«скорее перебдит»: лучше лишнее уведомление, чем пропущенный дроп.

## Чего скрипт не делает

Не логинится, не хранит пароли, не автопокупает, не обходит капчу и не
пытается обмануть очередь. Только чтение публичной витрины и сигнал в телегу.
